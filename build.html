Measures
Nitrate by UV, plus pH, TDS, temperature, a turbidity flag and GPS position.
Power
2× 18650 cells, 5 V output. Keep sustained draw under 4 A.
Logic level
3.3 V on every GPIO pin. 5 V will damage the Pi.
Hazard
UV-C light harms eyes and skin. It stays inside a closed chamber.

Settle these first

  1. UPS HAT and Pi 5. Waveshare's wiki lists Pi 3, 3B+ and 4B. Confirm that the HAT fits a Pi 5 and can power it.
  2. LED wavelength. This build uses 235 nm. Accept a 220 nm LED only with a measured spectrum; some "222 nm" listings actually specify 230–238 nm.
  3. Software. Drivers for UV, pH and TDS don't exist yet. Step 35 lists what's needed.
  4. Not covered. The field enclosure, intake spout and Raman add-on are not part of this build.

Rules

  1. Switch off before touching any wire.
  2. Finish each step's check before moving on.
  3. Fit the UV LEDs only at step 29, after the drivers pass.
  4. Never defeat the lid switch with an LED fitted.
  5. Results are screening only. Confirm anything near a limit with a certified lab.

Finished device

Concept only. The enclosure isn't designed yet, so this layout and size are estimates.

Still to design

  1. Water. The chamber needs its own sealed bay and a drain, so a spill can't reach the electronics.
  2. GPS. Its antenna sits under the display, so it may need an external antenna on the HAT's u.FL connector.
  3. Heat. The Pi 5 is boxed in under a HAT, so it needs a way to shed heat.
  4. Size. The Pi and HAT stack sets most of the height. A custom board could shrink it later.

Connect the display ribbon

Stage C · Wire sensors

09

Wire the turbidity sensor

  1. Plug the probe cable into the adapter board.
  2. Set the adapter switch to A (analog).
  3. Wire VCC to 5V and GND to GND.
  4. Build the divider from two 10 kΩ resistors, then wire its middle point to A0 on board 1.

Signal goes through the divider only. The sensor outputs up to 4.5 V and A0 must stay under 3.6 V.

Check

Only the divider's middle point touches A0. The signal wire does not reach A0 directly.

11

Wire the pH sensor

  1. Screw the pH probe's BNC plug onto its signal board.
  2. Connect the board to the sensor side of a DFR0504 isolator with the Gravity cable.
  3. Wire the isolator's controller side to the rails and to A0 on board 2.

Stage D · UV module

13

Wire the 15 V boost module

  1. UV LEDs need more than the 5 V rail can give. Listed forward voltages run up to 13 V.
  2. Wire the boost module's input to the 5V and GND rails.
  3. Run its output to the lid switch only. Leave the LED side open for now.
  4. Do not fit an LED. You set the voltage at step 27.

Check

The switch closes only when the chamber lid is shut. Confirm with continuity.

Wiring

Stage D · UV module

14

Build two LED drivers

  1. Build this circuit twice on prototype board, using one LMC6482 for both.
  2. Connect the first to #23 for 235 nm and the second to #24 for 275 nm.
  3. Power the op amp from the 3V rail and GND: pin 8 to 3V, pin 4 to GND.
  4. Check your LED's rated current. Current is 0.3 V divided by the sense resistor, so 15 Ω gives 20 mA.
  5. Leave the LED position open.

Check

Meter reads about 10 kΩ from each op amp + input to GND.

One driver

The 10 kΩ resistor holds the driver off while the Pi boots.

Stage D · UV module

15

Build two diode amplifiers

  1. Build this circuit twice using the second LMC6482: one for the sample diode, one for the reference.
  2. Wire the outputs to A1 and A2 on board 1.
  3. Keep the diode-to-op-amp wires short. At these currents, flux and long wires add noise, so clean the board.
  4. Confirm which diode pin is the anode. sglux connects it to the case, but check your datasheet.

Check

Solder joints are clean, and the two diodes have not been swapped between A1 and A2.

One amplifier

The small 3V divider keeps the output above 0 V, so the dark level can be measured.

Stage D · UV module

16

Build the UV chamber

  1. Make an opaque black holder with a lid that shuts out all room light.
  2. Use the four-window cell. Line up the LEDs, cell and sample diode about 10 mm above the cell's base, with about 20 mm from LED to diode.
  3. Mount the reference diode where it sees the LEDs directly, not through the cell.
  4. Keep the top half of the cell clear on all four sides. The Raman add-on uses it.
  5. Mount the LEDs' boards, but leave them out for now. Fit the diodes and lid switch.

Ordinary glass and most plastics block this UV. The cell must be quartz (fused silica).

Check

With the lid shut and the room lit, no light gets in. Check this at step 30 using the dark reading.

UV chamber

Hold the cell by its top rim. All four sides are polished, and fingerprints absorb UV. Mark one rim edge so the cell always goes in the same way round.

#!/usr/bin/env python3
"""Spectril bring-up checks.

  spectril_check.py adc 0x48 0        read one ADS1115 channel
  spectril_check.py uv 23             pulse an LED, read both diodes
  spectril_check.py uv 23 0.8421      same, plus absorbance against a blank
"""
import math
import subprocess
import sys
import time

from smbus2 import SMBus

UV_ADC = 0x48
SAMPLE_CH = 1
REF_CH = 2
RANGES = {0.256: 0b101, 0.512: 0b100, 1.024: 0b011, 2.048: 0b010, 4.096: 0b001}
SATURATED_V = 3.2


def read_once(bus, addr, ch, full_scale):
    config = 0x8183 | ((0b100 + ch) << 12) | (RANGES[full_scale] << 9)
    bus.write_i2c_block_data(addr, 0x01, [config >> 8, config & 0xFF])
    time.sleep(0.012)
    msb, lsb = bus.read_i2c_block_data(addr, 0x00, 2)
    raw = (msb << 8) | lsb
    if raw >= 0x8000:
        raw -= 0x10000
    return raw * full_scale / 32768


def read_volts(bus, addr, ch, samples=32):
    rough = read_once(bus, addr, ch, 4.096)
    full_scale = next((fs for fs in sorted(RANGES) if abs(rough) < 0.9 * fs), 4.096)
    return sum(read_once(bus, addr, ch, full_scale) for _ in range(samples)) / samples


def set_led(gpio, on):
    subprocess.run(["pinctrl", "set", str(gpio), "op", "dh" if on else "dl"], check=True)


def uv(gpio, blank=None):
    with SMBus(1) as bus:
        set_led(gpio, False)
        time.sleep(0.05)
        dark_s = read_volts(bus, UV_ADC, SAMPLE_CH)
        dark_r = read_volts(bus, UV_ADC, REF_CH)
        try:
            set_led(gpio, True)
            time.sleep(0.05)
            lit_s = read_volts(bus, UV_ADC, SAMPLE_CH)
            lit_r = read_volts(bus, UV_ADC, REF_CH)
        finally:
            set_led(gpio, False)

    if max(lit_s, lit_r) > SATURATED_V:
        sys.exit("Saturated: lower the amplifier resistor or the LED current.")
    sample, ref = lit_s - dark_s, lit_r - dark_r
    if sample <= 0 or ref <= 0:
        sys.exit("No signal: check the lid switch, 15 V rail and LED polarity.")

    ratio = sample / ref
    print(f"sample {sample * 1000:.2f} mV  ref {ref * 1000:.2f} mV  ratio {ratio:.4f}")
    if blank is not None:
        print(f"absorbance {-math.log10(ratio / blank):.4f}")


def main(argv):
    if len(argv) >= 3 and argv[0] == "adc":
        with SMBus(1) as bus:
            print(f"{read_volts(bus, int(argv[1], 16), int(argv[2])):.4f} V")
    elif len(argv) >= 2 and argv[0] == "uv":
        uv(int(argv[1]), float(argv[2]) if len(argv) > 2 else None)
    else:
        sys.exit(__doc__)


if __name__ == "__main__":
    main(sys.argv[1:])

  2. Put the meter across the boost module's output.

Stage G · Test and launch

28

Test the drivers with a resistor

  1. Put the 220 Ω resistor where the LED goes on the #23 driver, and close the lid switch.
  2. Run the first command: the pin must read low, and the resistor must have about 0 V across it.
  3. Drive it high: the resistor should read about 4.4 V, which means 20 mA.
  4. Drive it low, then repeat for #24.

Check

Both drivers follow their pins and read about 20 mA. After a reboot, both pins report lo.

Stage G · Test and launch

29

Fit the UV LEDs

  1. Shut down and set the switch to OFF.
  2. Remove the test resistor.
  3. Solder each LED to its driver, with anode to the lid switch side and cathode to the drain. Check polarity on the datasheet.
  4. Keep the LEDs on their mounts for heat.
  5. Close the lid and power up.

Check the UV signal

  1. Fill the clean cell with deionized water to at least 30 mm, and close the lid.
  2. Run each LED five times. The ratio should repeat closely.
  3. Note the 235 nm and 275 nm ratios. These are your blanks.

If you see "Saturated" on the 275 nm LED, increase its sense resistor. It is likely much stronger than the 235 nm LED.

Check

Five readings of each LED agree within 1%, and the dark check stays near 0.05 V.

Take a first nitrate reading

  1. Filter the nitrate check standard through a 0.45 µm filter into the rinsed cell.

Stage G · Test and launch

32

Calibrate pH

  1. Rinse the probe with deionized water, then put it in the pH 7.0 buffer. Wait for the reading to settle and note the voltage.
  2. Rinse, then repeat in the pH 4.0 buffer.
  3. Rinse and store the probe as its kit instructs.

Check

The two buffers give clearly different voltages, and a re-read of pH 7.0 matches within 0.1 pH. The rated accuracy is ±0.1.

Read pH channel

~/spectril_pi_code/.venv/bin/python ~/spectril_check.py adc 0x49 0

pH = 7 + 3 × (V7 − V) ÷ (V7 − V4)

Stage G · Test and launch

33

Calibrate TDS

  1. Rinse the needles, and put them in a known TDS or conductivity standard near 500 mg/L.
  2. Note the voltage and the DS18B20 temperature.
  3. Rinse again, then check that deionized water reads near 0 V.

Rated accuracy is ±10% of full scale, about ±100 ppm. Treat roughly 400–600 mg/L as "near limit".

Check

The standard reads clearly above deionized water, and a second reading matches within 5%. The response is not linear, so calibration has to come from known standards.

Read TDS channel

~/spectril_pi_code/.venv/bin/python ~/spectril_check.py adc 0x49 1

Output is 0–2.3 V for 0–1000 ppm.

Combined UV and Raman design

Proposed, not built or measured. The Build tab covers the UV channel only.

Sample to result

One cell, two beams (not to scale)

The laser runs above the UV beam, and Raman light is collected at 90°. That keeps most laser light out of the camera, so there is no dichroic or slit, and only two lenses: the collection lens and the camera's own. The laser's built-in lens only shapes its beam.

Measurement order (not to scale)

Run the same sequence on deionized water first for the blank. UV runs before the laser so laser heat can't shift the nitrate reading. Camera Module 3 exposures can run up to 112 s per frame. A changed second 235 nm reading rejects the test.

Wiring with the Raman add-on

Orange marks lines that feed the UV LEDs or laser. Raman adds only pin 11 and CAM/DISP 0. A bare laser diode needs a constant-current driver; never run it from the MOSFET alone. If your driver has an enable input, check its logic level and use that in place of the MOSFET. Check total draw against the UPS HAT's 4 A sustained limit. The camera needs camera_auto_detect=0 and dtoverlay=imx708,cam0 in config.txt.

Why combine them

  1. UV finds, Raman identifies. 235 nm reads nitrate, nitrite and organics as one number. A 1046 cm⁻¹ peak points to nitrate specifically. Untested here.
  2. UV warns Raman. High 275 nm absorbance suggests organics, and so fluorescence. Lengthen the exposure or flag the result.
  3. Raman adds sulfate. UV can't see it.
  4. UV stands alone. It still works if the Raman channel fails or isn't fitted.

Before buying the full Raman set

  1. Pass the UV gates first. Gates 1 and 2 in uv_sensing_strategy.md.
  2. Measure the laser line. It should stay under about 2 nm (32 cm⁻¹), or the sulfate and nitrate peaks start to merge.
  3. Test the cell. Run the laser on an empty cell and on deionized water. Silica and the cell's glue may add background.
  4. Test the camera. Pass means a repeatable 1046 cm⁻¹ peak at 10 mg/L N and a 981 cm⁻¹ peak at 250 mg/L.
  5. If it's short of light, try the HQ Camera with a 16 mm lens, about $100 more. I estimate about 19× more light, but removing its IR filter can't be undone. If that fails, keep Raman for high levels only.
